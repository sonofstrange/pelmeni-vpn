# Пельмени VPN Desktop — Qt Quick

ПК-клиент повторяет композицию Android-приложения: главный экран с отдельными
кнопками «Прокси» и «VPN», карточками туннелирования, активного сервера и
трафика, а также нижней навигацией «Главная / Люди / Настройки / Добавить».

## Безопасность и соединение

- SSH-туннель и локальный SOCKS4/SOCKS5 работают через Paramiko;
- неизвестный SSH host key требует подтверждения и сохраняется в `known_hosts`;
- пароль и TLS-сертификат хранятся через Windows DPAPI;
- режим VPN запускает отдельный Wintun/tun2socks и направляет системный трафик через SSH;
- исходные прокси-настройки восстанавливаются после отключения и сбоя;
- доступно автоматическое переподключение.

Основное окно работает без прав администратора. Отдельный VPN helper запрашивает их
только при включении VPN. Telegram-прокси использует отдельный порт и включается независимо.

## Запуск из исходников

```powershell
python -m pip install -r requirements.txt
python .\pelmeni_vpn_qt_api.pyw
```

## Сборка приложения и установщика

```powershell
powershell -ExecutionPolicy Bypass -File .\build-qt-final.ps1
```

Результаты:

- `dist\PelmeniVPN-Desktop.exe`;
- `dist\PelmeniVPN-Desktop-Setup-1.32.exe`.

Стандартный Inno Setup-установщик обновляет прежнюю desktop-версию в той же
папке и сохраняет профиль в `%APPDATA%\PelmeniVPN Desktop`.
