SSH Tunnel for Android
======================

Что умеет приложение
--------------------
- Все параметры задаются в интерфейсе: IP/домен, SSH-порт, пользователь, пароль и локальный SOCKS5-порт.
- Подключение и отключение одной кнопкой.
- Создает локальный SOCKS5-прокси на 127.0.0.1.
- Автоматически переподключает SSH после смены Wi-Fi/мобильной сети или включения VPN.
- Также переподключается при падении sshd, перезагрузке VPS, тайм-ауте, обрыве TCP/NAT и остановке локального SOCKS-порта.
- Может восстановить активный туннель после перезагрузки телефона.
- Работает как foreground service с постоянным уведомлением.
- Пароль шифруется ключом из Android Keystore и не зашит в APK.
- Перед первой передачей пароля показывает SHA-256 fingerprint SSH-ключа.
- Подтверждённый SSH-ключ закрепляется отдельно за каждым серверным профилем.
- Экспортируемые конфиги не содержат пароль: его нужно ввести после импорта.
- Стандартное окно SSH 4 МиБ рассчитано на быстрые линии с высоким RTT; профиль
  «Максимальная скорость» использует окно 8 МиБ.
- TCP-буферы согласованы с окном SSH, а SOCKS-потоки объединяют уже готовые
  мелкие записи без задержки первого пакета.
- При переключении Wi-Fi/мобильной сети приложение ждёт подтверждённый Android
  маршрут, перепривязывает SSH и пересоздаёт tun2socks без старых TCP-потоков.

Настройка Telegram
------------------
Telegram -> Настройки -> Данные и память -> Прокси -> SOCKS5
Сервер: 127.0.0.1
Порт: тот, который задан в приложении (по умолчанию 1080)
Логин и пароль прокси: пустые

Сборка и тесты
--------------
Открыть папку проекта в Android Studio, дождаться Gradle Sync, затем:
Build -> Build APK(s)

Либо из PowerShell с JDK 17+:
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug

Gradle Wrapper проверяет SHA-256 загружаемого дистрибутива.

Минимальная версия Android: 8.0 (API 26).

Обновление APK
--------------
Android разрешает обновлять установленное приложение только APK, подписанным
тем же закрытым ключом. Для релизов нужно хранить исходный keystore отдельно и
задавать его в signingConfig; debug.keystore с другого компьютера не совместим
с уже установленной сборкой.

Developer branding
------------------
Режим Huyna Debug переключается отдельным приложением Pelmeni Dev Control.
Основной APK не содержит логина, пароля или комбинации активации. Команды
контроллера защищены Android-разрешением уровня signature, поэтому контроллер
должен быть подписан тем же ключом, что и основной APK, и не предназначен для
публичного распространения.
