# Пельмени VPN Desktop 1.32

Официальный Windows-клиент Пельмени VPN с интерфейсом и форматами конфигурации Android-версии.

## Возможности

- независимые режимы VPN для всего компьютера и локального SOCKS-прокси для Telegram;
- системный VPN через Wintun и tun2socks, работающий независимо от сторонних VPN-клиентов;
- SSH-туннель с закреплением host key, TLS и автоматическим переподключением;
- несколько серверных профилей, PEL1-коды доступа и безопасный экспорт без пароля;
- управление пользователями, лимитами, бесплатными серверами и раздельным туннелированием;
- защищённое хранение паролей и TLS-данных через Windows DPAPI;
- IPv4-туннель и DNS-over-TCP внутри SSH для серверов без IPv6 forwarding.

Основное приложение работает без прав администратора. UAC запрашивает только отдельный VPN-helper при включении или выключении системного туннеля. Установщик использует стандартный интерфейс Inno Setup.

## Сборка

Требуются Python 3.10+, Inno Setup 6 и зависимости:

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\build-qt-final.ps1
```

Перед упаковкой сценарий запускает unit-тесты, собирает приложение и VPN-helper, затем создаёт `dist\PelmeniVPN-Desktop-Setup-1.32.exe`.

## Безопасность

Закрытый ключ активатора debug-режима не хранится в репозитории и не входит в официальный установщик. Публичный клиент содержит только ключ проверки подписи. Бинарные компоненты Wintun и tun2socks проверяются по SHA-256 перед запуском; их лицензии находятся в `runtime\licenses`.
